# 🌿 منصة طمأنينة (Tomanina Platform)
> **المساحة النفسية الآمنة لمتابعة النبض العاطفي للطلاب ودعم البيئة المدرسية والمجتمع المحلي**

---

## 📖 نظرة عامة (Overview)
منصة **«طمأنينة»** هي نظام متكامل وسري 100% مصمم للمدارس والمجمعات التعليمية بهدف:
1. **استشعار النبض النفسي اليومي للطلاب:** عبر 8 حالات شعورية متوازنة (الفرح، الهدوء، الحزن، القلق، الإرهاق، الملل، الغضب، الخوف) دون الكشف عن هوية الطالب لضمان الأمان النفسي الكامل.
2. **تقديم التدخل الفوري والمساندة:** توفير رسائل طمأنينة مخصصة وتمارين تنفس تفاعلية تهدئ الروع وتبني المرونة النفسية.
3. **توليد مبادرات تربوية آلية:** تحليل اتجاهات المشاعر السائدة واقتراح برامج إرشادية للمدرسة (مثل «واحة الطمأنينة» عند ارتفاع القلق أو الإرهاق).
4. **نظام طلبات الدعم والاستشارة السرية:** إمكانية إرسال تذاكر استشارة خاصة إلى المرشد الطلابي مع تشفير البيانات وأكواد متابعة سرية.
5. **لوحة تحكم إدارية ومحمية للمرشد:** تتضمن فرز التذاكر، تصدير التقارير، والنسخ الاحتياطي الشامل.

## 🏛️ بنية النظام (System Architecture)
يتكون النظام من منظومتين تعملان بتناغم تام:
- **تطبيق الأندرويد الأصلي (Android Jetpack Compose Native):**
  - **اللغة:** Kotlin
  - **إطار العمل:** Jetpack Compose + Material Design 3 (M3)
  - **قاعدة البيانات المحلية:** Android Room Database v3 مع فهارس مخصصة لسرعة الاستعلامات (`Indexes`) وتجزئة البيانات (`Pagination`).
  - **النمط المعماري:** MVVM (Model-View-ViewModel) مع `StateFlow` و `Coroutines`.
- **الخادم السحابي والبوابة الإلكترونية (Node.js & Web Portal):**
  - **الخادم الخلفي:** Node.js مدمج ومحصن أمنياً بدون أي تبعيات خارجية غير ضرورية (Zero npm runtime dependencies).
  - **البوابة الإلكترونية:** واجهة تفاعلية متجاوبة بنسبة 100% مع الهواتف الذكية والأجهزة اللوحية والمكتبية مع دعم كامل للغة العربية والاتجاه (RTL).

## 🚀 دليل التثبيت والتشغيل المحلي (Setup & Run Guide)

### 1. تشغيل خادم الويب والبوابة الإلكترونية:
```bash

cp .env.example .env

# 2. تشغيل الخادم
node server.js
# الخادم سيعمل افتراضياً على: http://localhost:3000
```

### 2. بناء وتشغيل تطبيق الأندرويد:
```bash

gradle assembleDebug

# تشغيل حزمة الاختبارات الآلية الشاملة
gradle :app:testDebugUnitTest
```

### 3. تشغيل اختبارات الخادم والـ API الآلية:
```bash
node test_server.js
```

## 🛡️ مواصفات الأمان والحماية (Security Specifications)
- **منع تخمين كلمات المرور (Rate Limiting & Account Lockout):** قفل تلقائي للحساب لمدة 15 دقيقة بعد 5 محاولات فاشلة متتالية لكل IP وبريد.
- **تأمين المقارنات الرقمية (Constant-Time Auth):** استخدام `crypto.timingSafeEqual` و SHA-256 لمنع هجمات التوقيت (`Timing Attacks`).
- **جلسات مشفرة عالية الأمان:** توليد توكنات عشوائية مشفرة بطول 256-بت (CSPRNG) صالحة لمدة 8 ساعات مع تجديد تلقائي وتنظيف للذاكرة.
- **حماية مسارات الخادم (Strict Path Traversal Protection):** حظر أي تلاعب بالمسارات (`..` و URL encoding) مع إرجاع كود `403 Forbidden`.
- **ترويسات الأمان الصارمة (HTTP Security Headers):**
  - `Content-Security-Policy (CSP)`
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: SAMEORIGIN`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Strict-Transport-Security (HSTS)`
- **التحصين ضد ثغرات الحقن (SQLi & XSS):**
  - تنظيف وفلترة جميع مدخلات النبضات وتذاكر الاستشارة.
  - تحصين حقول الـ CSV ضد هجمات حقن المعادلات (`Formula Injection`).

## 💾 النسخ الاحتياطي واستعادة البيانات (Backup & Disaster Recovery)
1. **تصدير كامل بنسق JSON (Full JSON Backup):** يتيح للمرشد بنقرة زر واحدة تنزيل نسخة رقمية موثقة بختم زمني لكافة نبضات الطلاب وتذاكر الاستشارة.
2. **استرجاع النسخة الاحتياطية (Instant JSON Restore):** إمكانية رفع واسترجاع البيانات المخزنة فوراً بعد التحقق من سلامة البنية والملف.
3. **تصدير الجداول (CSV Export):** تصدير سجلات النبضات بترميز UTF-8 مع تنظيف تام للفواصل وعلامات التنصيص لتسهيل قراءتها عبر Excel.

## 📊 مراقبة الأخطاء وصحة النظام (Health & Error Monitoring)
- **نقطة فحص الصحة:** `GET /api/system/health` توفر بيانات حية عن وقت عمل النظام (`uptime`)، الجلسات النشطة، واستهلاك الذاكرة.
- **سجل الأخطاء المحمي للمشرفين:** `GET /api/system/errors` يعرض الأحداث الطارئة ومحاولات الاختراق المسجلة في الذاكرة الدائرية الآمنة.
